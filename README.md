# Generatore di Frattali in C++

Un programma sviluppato in C++ per il calcolo e la generazione visiva di celebri figure matematiche ricorsive. 

Il sistema permette all'utente di selezionare diverse tipologie di algoritmi, calcolando le iterazioni necessarie e renderizzando l'output grafico risultante direttamente all'interno della console.

## Frattali disponibili
Tramite il menu del programma è possibile generare i seguenti set:
- **Insieme di Mandelbrot**
- **Insieme di Julia**
- **Triangolo di Sierpinski**
- **Frattale Personalizzato:** l'utente crea il suo frattale.

## Tecnologie utilizzate
- C++
- Gestione output su Console
